## 口径一：首年价和三年账，差的是几百块

38 元是每天两个时段限量抢购的价，售罄就按 68 元成交，页面没标注续费同价。99 元和 199 元属于“新购续费同价”，第二、第三年按当前价锁定。这两种写法的差别，在三年周期里很明显：

- 阿里云经济型 e 2核2G：99 × 3 = 297 元，价格确定。
- 阿里云轻量 2核2G：能抢到就是 38 + 68 + 68 = 174 元；但如果续费回归标准定价，第三年可能明显高于 68 元。页面没承诺的东西，不要写进预算。
- 雨云 2核4G：年付 7 折是循环折扣，328 × 3 ≈ 984 元，续费不跳价。

多出来的钱买的是 20M/30M 带宽和不限流量，不是 CPU。第三方汇总里还提到，阿里云部分非续费同价机型活动价 800 多元、续费可能回到 1400 元附近。这类机型下单前请自己在控制台看一眼续费报价，别只看首年那一栏。

选之前先想一件事：这台机器三年里，会不会因为带宽不够被你换掉。会的话，首年省下的几十块没有意义。

## 口径二：带宽怎么算钱，同一件事差价三倍

阿里云公网带宽的官方单价是 23 元/Mbps/月，折一年 276 元/M。拿这个尺子去量套餐，很多“送带宽”的说法就能算清楚了。

同一家厂商内部，加带宽的定价都能差三倍：经济型 e 2核4G 从 1M 升到 5M，年费从 599.93 元涨到 1640.33 元，增量 1040.40 元，约 260 元/年每 M；通用算力型 u2a 2核4G 同样从 1M 升到 5M，只从 504.60 元涨到 810.60 元，增量 306 元，约 76.5 元/年每 M。同样是“加 4M 带宽”，一个多掏一千，一个多掏三百。

带宽敏感的业务（图片站、下载站、图床、API 网关），下单前该看的是这个规格族的带宽加价，而不是首年总价。

反过来也能验证“峰值 200M”这类宣传：200M 按 23 元/M/月算就是 4600 元/月，不可能真给你独享。峰值带宽、流量包上限、调度策略三者一起决定你实际能跑多少。京东云那款 4核8G 标了 5M 带宽，同时写着月流量 500G 封顶，超了另付，这就是流量包的约束。雨云标的是上行/下行分开（2核4G 为 20M 上 / 30M 下）且不限流量，建站看下行，备份、推流、做代理看上行。

1M 到底能撑多少：理论下行约 128KB/s。一个没优化的 WordPress 首页连图片带脚本常在 1MB 以上，一个人打开就要 8 秒。页面只有 HTML 和接口请求、单次 30KB 的话，1M 能同时撑 4 个人左右。静态资源交给 CDN 或对象存储，1M 跑小站是够的；图片直接走源站，1M 一定不够。

## 口径三：轻量和云服务器不是一类东西

轻量应用服务器是套餐制，把实例、系统盘、月流量、峰值带宽打包卖，控制台简化，适合单机应用。ECS、CVM 是完整的弹性计算服务，能自定义网络、配安全组、接负载均衡、做弹性伸缩。同配置的常规 ECS，价格通常是轻量的 2–3 倍，省下来的正是网络能力和扩展性。

所以 38 元的机器不该拿去对标 199 元的机器，两者不在一个产品类别里。轻量普遍还有流量包上限、共享 CPU、网络隔离这些限制。经济型 e 也是共享计算资源模式，极端负载下实例之间会抢资源；u1 是独享计算资源，性能隔离更强。这也是 199 元那档比 99 元那档贵一倍的原因之一。

## 下单前确认这几件事

1. **有没有写“续费同价”**。没写就自己去控制台查续费报价，把第二年的数字写进预算。
2. **带宽是固定、峰值还是独享**，流量包给多少，超出怎么计费。京东云 4核8G 的月流量 500G 封顶就属于必须提前知道的限制。

4. **关联资源是否单独计费**：弹性公网 IP、快照、镜像、数据盘、负载均衡、NAT 网关、CDN，实例释放了这些不一定停。
5. **优惠券有没有真的抵扣**。先领券、再进控制台卡券管理确认入账，结算页看不到抵扣项就别付款。

## 常见问题

**38 元一年的服务器能做正式网站吗？**
技术上能跑，策略上不建议。它是轻量套餐、限时抢购、没标续费同价，200M 还是峰值口径，实际吞吐受流量包和调度策略限制。学习、演示、内部测试合适；对外经营的站，选续费同价的 99/199 档，或者把预算放到带宽上。

**1M 带宽能撑多少人同时访问？**
按 128KB/s 的理论下行算：页面 100KB，一秒一个人左右；页面 1MB，一个人要等 8 秒。把图片、CSS、JS 放到 CDN 或对象存储，1M 只跑 HTML 和接口，小站是撑得住的。

**轻量应用服务器和云服务器差在哪？**
套餐制和弹性计算的区别：峰值带宽加流量包对固定带宽，共享 CPU 对可选独享，单机对支持负载均衡与弹性伸缩。同配置常规 ECS 价格通常是轻量的 2–3 倍。

**第二年会不会涨价？**
看页面有没有写续费同价。阿里云 99 元和 199 元写了；38 元抢购价没写。雨云的季付、半年付、年付折扣属于循环折扣，续费仍按折后价。没写的，一律按标准定价做预算。

**按月买还是按年买？**
算盈亏平衡点。阿里云 c9i 2核4G 按量 0.3873 元/小时、包月 185.91 元，平衡点约 480 小时，也就是每月跑满 20 天就该包月；经济型 e 2核2G 是 0.094 元/小时对 19.86 元/月，平衡点约 211 小时（8.8 天）。长期在线的业务一律包年包月，年付相对月付年化普遍省三成，u1 这类入门款能省近五成。但同一产品线里差异很大：轻量 2核1G 月付 34 元、年付 408 元，等于一分没省；2核4G 月付 70 元、年付 379 元，只有月付年化的 45.1%。别默认年付一定划算。
